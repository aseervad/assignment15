✅ Objective:
To integrate a countdown timer into the Speaking Test interface using the react-timer-hook library.

🧩 Key Features Implemented:
Countdown timer with 2-minute duration using react-timer-hook

Visual feedback (green/red styling based on time remaining)

Start, pause, and resume controls

Timer is shown when test starts

Alert shown when time expires
